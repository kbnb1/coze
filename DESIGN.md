# ShieldLink - Game Account Security Platform

## Design Style: Cyber Tech / Dark Neon

### Brand Identity
- **Name**: ShieldLink (盾连)
- **Concept**: Digital fortress for game account security
- **Imagery**: A glowing cyber shield pulsing with neon energy, protecting digital assets in a dark digital landscape

### Color System
- Primary: #00F0FF (Electric Cyan) - trust, security, technology
- Secondary: #BF00FF (Neon Purple) - power, premium feel
- Danger: #FF003C (Alert Red) - threat detection, warnings
- Success: #00FF88 (Matrix Green) - safe, verified
- Background: #0A0A0F (Deep Black)
- Surface: #12121A (Micro-bright Black)
- Border: rgba(0,240,255,0.15)
- Text Primary: #EAEAEA
- Text Secondary: #555570

### Typography
- Data/Numbers: JetBrains Mono (monospace, tech feel)
- UI Text: System default
- Labels: uppercase, letter-spacing: 2-3px, size 11px
- Titles: bold, size 20-24px

### Core Visual Elements
- Neon glow borders with cyan shadow diffusion
- Small border radius (6-8px) for sharp tech aesthetic
- Gradient accent bars (cyan to purple)
- Scan line decorations for HUD feel
- Pulsing status indicators

### Design Prohibitions
- No warm colors as primary
- No large border radius (max 12px)
- No pure black shadows (use cyan-tinted)
- No emoji as icons
- No rounded/playful elements
